In this chapter, you will run one OpenTelemetry Collector in Agent mode and
observe how it receives host metrics, traces, and logs. You will validate the
telemetry locally, optionally find it in Splunk Observability Cloud, and then
upload the Agent configuration to OTel Collector Config Builder for the next
chapters.
