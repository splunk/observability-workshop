Explore how to get insight to end user experience with Splunk Observability Cloud, and how it connects the front end to underlying application issues for better context and faster MTTx. 

## Workshop Overview

During this workshop, we will cover the following topics:

- Understand end user behavior with Digital Experience Analytics (DXA)
- See what app users see with Session Replay
- Monitor performance for real users with Real User Monitoring (RUM)
- Proactively test frontend performance with Synthetics

By the end of this workshop, you'll be familiar with understanding application health and success through the lens of end user experience.
