Our Astronomy Shop application is instrumented end-to-end with Splunk Observability Cloud, including user sessions with Real User Monitoring (RUM).

We use **Digital Experience Analytics (DXA)** as a lens on top of data we already get from RUM to better understand user behavior.

This means that we can create visualizations without having to further customize application code (unless we want to!).

Let's explore what this looks like to understand:
- Feature adoption,
- frustration, and
- funnels!
