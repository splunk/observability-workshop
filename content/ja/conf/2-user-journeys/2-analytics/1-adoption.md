Astronomy Shopの商品詳細ページで「Ask AI」機能を見たことを覚えていますか？テキスト入力フィールドの下に提供されているクイックプロンプトを含め、顧客がその機能をどのように使用しているかを理解したいと思います。
![Ask AI feature on Astronomy Shop product details](../images/ask-ai-astronomy.png)

{{% exercise title="機能の採用状況を理解する" %}}

DXAプロジェクトのanalysesタブに移動し、時系列「AI feature adoption」をクリックします。
![timeseries with quick prompts](https://colony-recorder.s3.amazonaws.com/files/2026-03-19/c0716b91-9c74-41f2-9545-dcf6cd46a1fa/ascreenshot_f11164e9f0274895b40466f0b51c8c3e_text_export.jpeg)

{{< tabs >}}
{{% tab title="質問" %}}

すべてのAIクイックプロンプトは均等に使用されていますか？最も人気のあるものはどれですか？

このチャートはなぜ役立つと思いますか？

{{% /tab %}}
{{% tab title="回答" %}}

プロンプトの人気度は、ワークショップの参加者のインタラクションによって異なります！

ユーザーが実際にアプリの機能を利用しているタイミングを示す時系列があることで、その機能が成功しているか、より良く機能させるために何かを変更する必要があるか、またはこの機能を根本的に見直す必要があるかをより深く理解できます。

{{% /tab %}}
{{< /tabs >}}

チャート上のポイントをクリックして関連するセッションリプレイを読み込み、セッションリプレイをクリックして再生を視聴します。

![adoption replay](https://colony-recorder.s3.amazonaws.com/files/2026-03-19/2fe1c767-3cae-416d-b01f-8dd0ac4ad22c/ascreenshot_1204a5dfc14a43dda82ee196b8c657c2_text_export.jpeg)

{{< tabs >}}
{{% tab title="質問" %}}

リプレイで何が見えますか？

機能の採用状況において、セッションリプレイにはどのような価値があると思いますか？

{{% /tab %}}
{{% tab title="回答" %}}

セッションの詳細は上部に表示され、インタラクションは左側のタイムラインと再生バーの両方に表示されます。右側のペインにはエンドユーザーが見て体験した内容が再現されます。

リプレイを視聴することで、機能が期待通りに採用されていない場合に何が起きているかを把握できます。たとえば、ユーザーがその機能をスクロールして通り過ぎているのか、または別の要素やポップアップによって隠されているのかがわかります。
