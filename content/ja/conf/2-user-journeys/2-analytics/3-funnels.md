個々のユーザーアクションが時系列で追跡されることは確認しましたが、エンドユーザーが期待どおりにアプリを使用しているかどうかはどのように確認すればよいでしょうか？

{{% exercise title="ファネルを探索する" %}}

Project Analysesに戻り、Homepage to Order Confirmationファネルを開きます。チャートが「All users」でフィルタリングされていることを確認してください。

このファネルは、ホームページから開始し、商品を閲覧し、チェックアウトしたユーザーをキャプチャしています。次のステップに進む前にユーザーが離脱した場合、それも記録されます。

{{% notice title="留意点" style="primary"  icon="lightbulb" %}}自分のアプリケーションにおける一般的なユーザージャーニーについて考えてみてください。モニタリングしたいステップをどのように定義しますか？{{% /notice %}}

セグメントをクリックして、関連するユーザーセッションを表示します。

![funnel for checkout](../images/funnel.png)

{{< tabs >}}
{{% tab title="質問" %}}

1. このようなファネルをあなたのアプリでどのように活用できますか？
1. どの離脱セグメントがより予想される動作で、どれが最初に調査する価値がありますか？

{{% /tab %}}
{{% tab title="回答" %}}

1. ファネルは、期待されるユーザーの成功をモニタリングするためだけでなく、問題のトラブルシューティングやコンバージョン向上のためのアプリ最適化にも一般的に使用されます。
1. ホームページや商品ページへのアクセス、またはカートの放棄は、注文後に注文確認が完了しないことよりも予想される動作です。

注文後に非常に高い割合のユーザーが注文確認を受け取れていないという事実は、実際には深刻な問題です！
